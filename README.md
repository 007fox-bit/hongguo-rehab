# 红果戒毒所 · 网页版

娱乐向「戒红果短剧」小程序 —— 零依赖纯静态网页版，浏览器双击即开，数据只存在你自己的浏览器里。

## 怎么玩

**直接双击 `index.html`**，用任意现代浏览器（Chrome / Edge / 微信内置浏览器均可）打开即可，不需要联网、不需要安装任何东西。

如果想要更好的体验（手机端全屏、可添加到主屏幕当 app 用），可以用任意静态服务器托管，例如：

```
cd web
python -m http.server 8080
```

然后浏览器打开 `http://localhost:8080`。

## 九大模块（与小程序版完全一致）

| 模块 | 功能 |
|------|------|
| 🩺 F1 入所体检 | 10 题自测，判定「轻度 / 中度 / 重度 / 病危」中毒等级 |
| 📜 F2 戒断档案与契约 | 签康复契约：治疗模式、每日限额、戒断理由、娱乐化违约惩罚 |
| ✅ F3 日常打卡 | 每日签到、连续天数、最长记录、28 天热力图、勋章解锁 |
| 🆘 F4 瘾发急救包 | 5 分钟强制冷静倒计时（不可跳过）+ 替代活动转盘 + 清醒暴击语录 + 4-7-8 呼吸引导 |
| 📒 F5 时间账本 | 记录省下的时间，折算成多睡几小时 / 读几页书 / 陪家人几小时，勋章墙 |
| 🎮 F6 替代内容 | 戒毒段子、戒断冷知识、记忆翻牌小游戏 |
| 💬 F7 病友社区 | 发帖（含敏感词过滤）、点赞、康复排行榜、结对病友（虚拟） |
| 🎓 F8 出院系统 | 连续康复 7 天可申请出院、生成出院证明、复健通道（无羞辱） |
| ⚠️ F9 提醒预警 | 高危时段设置（夜间岗）、减少动画开关 |

## 说明

- **纯娱乐**：本所不能监控或屏蔽红果 App，主打自报 + 打卡 + 契约 + 急救，靠的是自觉。
- **数据本地化**：所有数据存在浏览器 localStorage，前缀 `hg_`，不上传任何服务器；在「我的 → 清空所有数据」可一键删除。
- **隐私提示**：病友圈为本地模拟社区，请勿填写真实隐私信息。
- **冷静不可绕过**：倒计时基于真实时间戳计算，关闭页面重开仍继续计时。
